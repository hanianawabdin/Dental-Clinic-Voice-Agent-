# Dental Clinic Voice Agent

## About the Project
Many small dental clinics still book appointments over the phone.
The receptionist can talk to only one person at a time, and patients
often forget their appointments.

Our project is a voice agent for a dental clinic. The patient talks to
it in English or Urdu on a web page. It can book, change and cancel
appointments. It also keeps the status of each appointment, makes
reminder lists for the staff, and passes emergency calls to the
receptionist.

This is our project for CSC-331 Software Engineering at Namal
University, Mianwali.

Requirement Provider: Muhammad Huzaifa, Cortex Digital Systems Pvt Ltd

## Tools We Use
- Website: React, Vite, Tailwind CSS
- Voice: LiveKit Agents, Deepgram, Uplift AI, Fish Speech
- AI model: Groq (Llama 3.1)
- Server: Python, FastAPI, SQLAlchemy, APScheduler
- Database: PostgreSQL (Supabase), SQLite
- Testing: pytest, Postman
- Hosting: Render or Railway, Vercel
