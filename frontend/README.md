# DentalCare Voice Assistant frontend

React + Vite prototype for the Dental Clinic Voice Agent project.

## Run locally

1. Install Node.js LTS.
2. Run `npm install` inside this folder.
3. Run `npm run dev`.
4. For production, run `npm run build`. Vite creates `dist/`.

## Prototype limitations

- Appointment records are sample data held in browser memory and reset on refresh.
- Booking does not save to a server or database.
- The voice assistant is a visual preview. LiveKit, speech recognition, speech synthesis and the LLM are not connected.
- Do not enter real patient information. Add secure backend, authentication and privacy controls before any clinic use.
